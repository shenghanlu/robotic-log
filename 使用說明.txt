2026 AI 工具書推薦選購網站｜GitHub Pages 版本
==============================================

網站檔案：index.html（已移除所有書籍封面圖片，保留 8 本書的博客來商品頁連結）

【直接開啟】
1. 在電腦上雙擊 index.html 即可開啟。
2. 書籍選擇、個人書單、順位調整、JSON 匯出與本機管理後台均無需額外安裝。
3. 點選「博客來看書籍介紹」會另開網頁，該功能需要網路。

【上傳 GitHub Pages】
1. 新增 GitHub Repository。
2. 將 index.html 上傳至儲存庫「根目錄」，不要包在子資料夾內。
3. 到 Settings → Pages → Build and deployment → Deploy from a branch。
4. 選擇 main 分支與 / (root)，然後儲存。
5. 網址一般為 https://<你的帳號>.github.io/<儲存庫名稱>/ 。

【重要：GitHub Pages 是靜態網站，不會自動集中每位教師資料】
- 教師用自己的電腦填寫，資料儲存在各自瀏覽器的 localStorage 中。
- 管理者不會在不同電腦自動看到教師資料，無法靠 GitHub Pages 的靜態 HTML 完成共用資料庫。
- 教師須匯出個人 JSON 檔並交給管理者，管理者在後台批次匯入後，再匯出 Excel。
- 若要真正做到所有老師線上填寫、自動集中資料、可靠登入與防止偽造／竄改，需要額外串接後端服務與資料庫，不能僅上傳 index.html。
- 目前「管理員密碼」只在使用者瀏覽器本機驗證，不是伺服器級別存取控制。公開部署時不可將任何實際敏感資料或高權限憑證放入 HTML。
- 網頁使用的資料存放於瀏覽器，不應視為安全或永久的集中儲存；請定期匯出備份。
